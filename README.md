# Настройка виртуальных номеров в UIS

Скрипт сам выполняет в личном кабинете UIS (https://app.uiscom.ru/) рутинные действия с виртуальными номерами:

- назначает номеру сценарий;
- добавляет номера в правило выбора АОН;
- удаляет номера из правила выбора АОН.

## Почему через браузер, а не через API

У UIS нет методов API для настройки виртуальных номеров и для работы с правилами выбора АОН. Поэтому скрипт управляет браузером Chrome через Selenium и нажимает в личном кабинете те же кнопки, что и человек.

Отсюда следует:

- скрипт работает медленно: после каждого действия он ждёт, пока страница загрузится;
- если UIS поменяет интерфейс (надписи на кнопках, поля, меню), скрипт может перестать работать, и его придётся поправить.

## Что нужно для запуска

- Windows и установленный Google Chrome.
- Python и виртуальное окружение `.venv` в папке программы с пакетами `selenium` и `python-dotenv`.

Если `.venv` ещё нет, его можно создать так:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install selenium python-dotenv
```

## Файлы

| Файл | Зачем нужен |
|---|---|
| `settings.py` | сама программа |
| `.env` | логин, пароль и настройки |
| `num.txt` | список номеров, с которыми работать |
| `chrome_profile/` | профиль Chrome, где хранится вход в UIS (создаётся сам) |

## Настройка `.env`

Создайте в папке программы файл `.env`:

```
URL=https://app.uiscom.ru/
LOGIN=ваш_логин
PASSWORD='ваш_пароль'
HEADLESS=true
SCENARIO_NAME=Название сценария
RULE_NAME=Название правила выбора АОН
```

| Переменная | Что означает |
|---|---|
| `URL` | адрес личного кабинета. Если строку не указать, используется `https://app.uiscom.ru/` |
| `LOGIN`, `PASSWORD` | логин и пароль от UIS. Если в пароле есть спецсимволы, возьмите его в одинарные кавычки |
| `HEADLESS` | `true`: браузер работает в фоне, без окна. `false`: окно браузера видно |
| `SCENARIO_NAME` | сценарий, который назначается номерам. Пишите название так же, как в UIS |
| `RULE_NAME` | правило выбора АОН, в которое добавляются или из которого удаляются номера. Пишите название точно так же, как в UIS |

`LOGIN`, `PASSWORD`, `SCENARIO_NAME` и `RULE_NAME` обязательны: без любой из них программа сразу остановится с ошибкой `KeyError`.

В `.env` лежит пароль, поэтому не пересылайте этот файл и не выкладывайте его.

## Список номеров `num.txt`

По одному номеру на строку, в том же виде, в каком номер показан в UIS. Пустые строки пропускаются.

```
74951234567
74951234568
```

## Первый запуск: вход в UIS

При входе UIS может показать капчу. Её нужно пройти руками, и в фоновом режиме это невозможно. Поэтому в первый раз:

1. В `.env` поставьте `HEADLESS=false`.
2. Запустите программу (см. ниже). Откроется окно Chrome, программа сама введёт логин и пароль.
3. Если появилась капча, пройдите её. Когда откроется личный кабинет, вернитесь в консоль и нажмите Enter.

Вход сохранится в папке `chrome_profile`, и дальше можно снова ставить `HEADLESS=true`. Если вход когда-нибудь слетит, программа напишет «В фоне войти не получится». Тогда повторите эти шаги.

## Запуск

Из папки программы:

```powershell
.\.venv\Scripts\python.exe settings.py
```

Программа выведет список номеров из `num.txt` и спросит режим:

```
1 - настройка и добавление, 2 - удаление, 3 - добавление в правило:
```

Введите цифру и нажмите Enter.

### Режим 1: настройка и добавление

1. Открывает «Виртуальная АТС» → «Виртуальные номера и правила».
2. Для каждого номера из `num.txt` создаёт правило со сценарием `SCENARIO_NAME`. Если у номера нет кнопки «Создать правило», значит номер уже настроен: программа напишет «Номер … уже настроен — пропускаем» и перейдёт к следующему.
3. Затем добавляет все номера в правило выбора АОН `RULE_NAME` (как в режиме 3).

### Режим 2: удаление из правила

Открывает правило выбора АОН `RULE_NAME` и удаляет из него номера из `num.txt`. Если номера в правиле нет, программа напишет «Нет номера …» и пойдёт дальше. Сценарий у номеров при этом не меняется.

### Режим 3: добавление в правило

Открывает правило выбора АОН `RULE_NAME` и добавляет в него номера из `num.txt`. Сценарии номеров не трогает.

В режимах 2 и 3 правило сохраняется после каждых 10 номеров и в конце. Если программа упадёт посередине, уже сохранённые изменения останутся.

## Что важно знать

- В выпадающих списках (сценарий, номер в правиле) программа выбирает первый вариант, который предложил UIS. Если в UIS есть похожие названия, например «Временно» и «Временно 2», проверьте, что выбралось нужное.
- Пока программа работает, не открывайте этот же профиль Chrome вручную и не закрывайте окно браузера (при `HEADLESS=false`).
- В конце браузер закрывается сам, даже если программа упала с ошибкой.
